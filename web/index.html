          Advanced

          IRC commands

          Anything starting with / is sent to the server. These are handled locally; every other slash command is forwarded to IRC as typed, so the whole protocol is reachable from the message box.

          • /join #channel — join a channel
          • /part [#channel] — leave a channel
          • /query nick [message] — open a private conversation
          • /msg nick text — send without opening a conversation
          • /notice nick text — send a notice
          • /nick name — change nickname
          • /topic [text] — read or set the topic
          • /me action — send an action
          • /raw COMMAND — send a literal IRC line

          The console, at the top of the conversations, shows every line the network sends and sends what you type there as the IRC line itself — no slash needed. That is where to look, and to type, when a connection or a NickServ exchange does not behave.
