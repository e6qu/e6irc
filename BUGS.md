# e6irc — Known bugs

**This file is a tripwire, not a backlog. It must stay empty.**

Under the No-Deferral Rule (AGENTS.md), a bug that is found is a bug that is
*fixed in the same change*, or a decision that is *put to the human* — never a
row parked here to be done "later". `tools/check-no-defer.sh` fails the gate if
an open `- [ ]` entry appears below, so anything added here is a visible
violation of the rule, not a task.

If you are tempted to add an entry: fix it instead, or escalate it as an
explicit question. There is no third option.
